-- Project Description --

Retro Snake is a python game built with the old school lightweight Pyxel engine. 
The development of this project was made as an attempt to experiment with python game development in the pixel-like old school way. 

How to use:

-Follow the link.
-Wait a couple of seconds.


-Enjoy! 

!! The files are under refactoring, the link may be unresponsive.
